hyt

Read radio

Reads every settings file from the radio into a new folder and opens it. Reading does not change the radio. CPS must not be using the port.

Save as

Saves the whole configuration, including your changes, as a new folder (same layout as hyt read). You then continue editing from the new folder.

Write to radio

  1. Read the whole radio into the backup folder.
  2. Refuse to continue unless it is the same radio (model, serial number, RCDB version).
  3. Write the settings files in CPS's order.
  4. Wait for the radio to restart, read it back and compare every written file.

Export CPS template

Saves the configuration as shown, including unsaved changes, as a template file (.tpl) that CPS can import into its template library. The radio is not changed.

Import CPS template

Takes the template's settings for the radio of the open folder (model, serial number and RCDB version stay the radio's), saves them as a new folder and opens it. Files the template lacks are kept from the open folder. The radio is not changed: check the result, then write it.
